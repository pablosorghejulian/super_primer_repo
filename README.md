# WebSprint 30

Aplicación web de productividad para ejecutar un plan comercial de 30 días, registrar prospectos, administrar proyectos y controlar objetivos de ingresos.

## Tecnologías

- Next.js
- React
- TypeScript
- CSS responsive
- Persistencia con `localStorage`

## Estado

Proyecto demostrativo de portfolio. El código fue adaptado para ejecutarse y publicarse fuera de ChatGPT Sites.

## Ejecución local

```bash
npm install
npm run dev
```

## Producción

```bash
npm run build
npm run start
```

> Los datos se guardan únicamente en el navegador actual y no se sincronizan entre dispositivos.
